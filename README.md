# playwright_github_actions

## Allure Report Setup

This project is configured to generate Allure reports via Playwright.

### Run tests with Allure reporting

```bash
npm run test:allure
```

### Generate the report

```bash
npm run allure:generate
```

### Open the generated report

```bash
npm run allure:open
```

### Serve the report directly

```bash
npm run allure:serve
```
